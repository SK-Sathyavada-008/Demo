# Introduction
This repository contains Java code examples for beginners. It demonstrates core Java concepts such as loops, conditional statements, and array manipulation.

## How to Run the Program
1. Clone the repository:
   git clone https://github.com/SK-Sathyavada-008/Demo.git
2. Compile the Java program:
   javac ActivitySelection.java
3. Run the compiled program:
   java ActivitySelection

## Array Programs
- `SortingAlgorithms.py`: A Python script implementing Merge Sort and Quick Sort for sorting integers.

## Java Concepts Covered
- Memory allocation in C++
- React Hooks and Frontend State Management
- SQL Join queries and Database Indexing
